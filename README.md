## 📖 项目简介

本项目是一份面向**医疗行业零售侧**的 AI 智能体应用场景全景设计文档，以交互式 HTML 形式呈现。

核心回答三个问题：
- **在哪里用？** 覆盖药店、电商、互联网医院、慢病管理等零售场景
- **怎么用？** 每个场景提供完整的产品设计方案、技术架构和落地路径
- **有什么风险？** 每个场景附有合规风险分析与应对策略

适合以下读者参考：**AI 产品经理 / 医疗健康创业者 / 医药电商团队 / 互联网医疗从业者**

## 📐 底层技术支撑（文档内容节选）

本全景图中所有场景共享以下技术底座：

- **数据与知识层** — 药品说明书知识库 RAG、症状-适应症映射模型、EHR 患者档案
- **模型与推理层** — LLM + RAG 检索增强、意图分类 Fine-tuning、OCR 票据识别
- **安全与合规层** — 严重症状强制就医导流、处方药分级权限管控、数据脱敏等保三级

### 关键合规要点

| 合规维度 | 要求 |
|---------|------|
| 处方药管控 | OTC 与 Rx 严格区分，处方药不得无处方推荐 |
| 就医导流 | 重症/急症强制引导线下就医 |
| 数据隐私 | 等保三级，健康数据脱敏，用户授权管理 |
| 专业兜底 | 药师/医师审核机制，AI 输出不替代医疗诊断 |
